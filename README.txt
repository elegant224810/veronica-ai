VERONICA — NEW CRYSTAL ASTRAL BUILD
===================================
Start fresh with this package.

Files:
- index.html — complete responsive dashboard
- veronica-character.png — your supplied new anime mascot, checkerboard background removed
- dashboard-reference.png — your supplied dashboard design reference

Android + GitHub:
1. Extract this ZIP on your phone.
2. Open your GitHub repository.
3. If you want a completely fresh project, create a new repository. Otherwise upload these files to the root of the existing repository and replace its old index.html.
4. Upload all three files together and commit to main.
5. Enable Settings > Pages > Deploy from a branch > main > /(root) > Save.

Features in this frontend:
- Mobile-first crystal-purple interface
- Home, Chat, Memory, Skills, Tools, Logs and Settings
- Local browser memory notes and activity logs
- Demo chat interaction and optional browser speech input

Important:
This is the dashboard frontend, not a connected AI agent yet. Real model responses, cloud sync and integrations need a secure backend. Never put private API keys in browser code.
